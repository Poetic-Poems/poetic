# Contributing to Poetic

Thanks for your interest in contributing! This document points you to the resources you'll need.

## For framework changes

See the [Contributing section](README.md#contributing) in the README for where framework changes belong, the branch workflow, commit message format, and local development instructions.

## For poem collections (consumer repos)

If you've created your own poem repository using Poetic as a base, you own that repository's contribution guidelines. The framework itself is maintained in [Poetic-Poems/poetic](https://github.com/Poetic-Poems/poetic).

## Questions?

[Open an issue](https://github.com/Poetic-Poems/poetic/issues) to ask a question or report a problem.
