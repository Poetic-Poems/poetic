**Severity:** Low

`package.json:21` pins `^14.2.0`; `npm outdated` reports `markdown-it
14.3.0 (wanted) / 15.0.0 (latest)` as the only outdated production
dependency. This has been open since the 2026-07-31 review (its
F-DEPS-01/R-12).

v15.0.0's breaking changes are: removed `markdown-it/lib/*` subpath
exports; `linkify-it` v6 behavioural changes (fuzzy links/auth-part
checking off by default); `validateLink`/`normalizeLink`/`normalizeLinkText`
moved from instance properties to prototype methods; package root resolves
prebuilt ESM/CJS. The sole construction site, `src/tools/markdown.js:21-29`
(`new MarkdownIt({ html: true, typographer: true })`), sets no `linkify`
option, has no subpath import (`grep -rn "markdown-it/lib" src/` empty),
and no `validateLink`/`normalizeLink` override — none of v15's four
breaking-change categories appear reachable from this codebase's actual
usage, so the bump looks low-risk on inspection.

**Suggested fix:** Bump to `^15.0.0` in a standalone PR; run `npm test`
(`test/markdown.test.js`, `test/yaml-to-poem-roundtrip.test.js`) and `npm
run build` to confirm no rendering-output drift before merging, given this
dependency's role in postscript/analysis rendering.
