**Severity:** Low

`src/tools/blogger-auth.js:336-342` carries its own `escapeHtml()`, the
fourth near-identical copy in `src/tools/` alongside
`aggregate-render-core.js:33`, `serve-static.js:115` and
`poem-to-raw.js:151`. Raised as a non-blocking observation on PR #165
(https://github.com/Poetic-Poems/poetic/pull/165#issuecomment-5275828115),
which fixed an unescaped-reflection bug in `blogger-auth.js`'s OAuth error
path by copying the pattern rather than sharing it — a reasonable call at
the time, since `blogger-auth.js` is a standalone CLI that probably
shouldn't pull in `aggregate-render-core.js` just for this helper.

The copy is also now part of `blogger-auth.js`'s `module.exports`
(`:620`), added solely so `test/blogger-auth.test.js` can exercise it
directly — the only one of the four copies exposed as a public export for
that reason.

**Suggested fix:** Extract a shared `src/tools/html-escape.js` exporting a
single `escapeHtml()`, and have all four call sites (and their tests)
import it instead of each carrying its own copy. Worth doing together
rather than piecemeal, since the four implementations should already be
byte-identical and a shared module removes the risk of them silently
drifting apart.
